Product questions still to resolve
  • Search: define patient, session and work search scope.
  • Session documents: confirm which document creation and dictation/editing capabilities belong in the first release.
  • Patient retention: clarify when EHR patients are retained after saving details or creating care/work without a session.
  • Existing decisions: task placement, suggestion expiry, retention policy, encounter lifecycle, later EHR linking and minimum note workflow remain open. EHR note delivery is excluded for now.

These questions are recorded in Notion; prototype features do not automatically become release requirements.

Aligned with Notion on 2 October 2026. Intended experience, not a claim that every requirement is implemented.
